# DLP estimate

`GF(p^r)` 上の離散対数問題（DLP）に対する Shor 型アルゴリズムの、Qualtran ベースの資源見積り。

## 環境構築

```bash
uv sync --locked
```

## 使い方

### 資源見積り

```bash
uv run python script/estimate_qualtran.py
```
